AI-ассистент для кода умный, но отрезан от инфраструктуры. Агент умеет рассуждать, но не может действовать с ресурсами AWS. Model Context Protocol (MCP) соединяет одно с другим. На этом chalk talk весь стек AWS вокруг MCP разбирается вживую: Kiro как AI IDE для разработки по спецификациям (spec-driven), больше 60 MCP-серверов AWS для мгновенного доступа к облаку, Strands Agents SDK для автономных рабочих процессов и Amazon Bedrock AgentCore для продакшена. Один MCP-сервер показан на трёх уровнях (IDE разработчика, автономный агент, рантайм в продакшене) без переписывания. Вопрос для обсуждения: был ли MCP ошибкой, или он по-прежнему нужен, чтобы строить настоящих AI-агентов на AWS.
