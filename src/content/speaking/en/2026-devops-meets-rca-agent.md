How to build your own root cause analysis agent on Amazon Bedrock AgentCore: the Model Context Protocol (MCP) architecture and the role it plays in how an agent gets its tools and context, Amazon Bedrock as the model layer, and the design decisions behind a custom RCA agent. A second example in the talk is an agent that tracks AI trends. This is the first version of the talk that later grew into [Building an RCA Agent with Amazon Bedrock AgentCore](/en/speaking/2026-rca-agent-agentcore/) at AWS Community Day Central Asia.

A one-hour session at DevOps Meets 2.0.26 "New Reality with AI", the community conference organised by Wargaming in Vilnius, Lithuania, on 19 March 2026.
