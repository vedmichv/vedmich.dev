A hands-on workshop on getting started with large language model (LLM) applications and inference on Amazon EKS with NVIDIA GPUs. The labs show how to deploy and manage production-grade LLM workloads with Amazon EKS, AWS services and open-source tools. The AWS workshop it is based on covers GPU infrastructure, serving a model with vLLM, observability with NVIDIA DCGM, Prometheus and Grafana, an agent built with the Strands Agents SDK on the self-hosted model, inference benchmarking, fine-tuning with LoRA, and RAG.

A two-hour session on the workshop day of [AWS Community Day Malta 2026](https://www.awscommunityday.mt/), Thursday 15 October 2026, 09:45-11:45, in room Sonata A at the Hard Rock Hotel Malta in St Julian's. The talks day followed on 16 October. The labs come from the public AWS workshop [Generative AI on EKS using NVIDIA GPU](https://catalog.workshops.aws/genai-on-eks/en-US), which you can also run in your own AWS account.
