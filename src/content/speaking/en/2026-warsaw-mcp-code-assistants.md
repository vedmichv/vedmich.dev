An AI coding assistant is smart but disconnected from your infrastructure. An agent can reason but cannot act on your AWS resources. The Model Context Protocol (MCP) brings the two together. This chalk talk walks through the full AWS MCP stack live: Kiro as a spec-driven AI IDE, 60+ AWS MCP servers for instant access to the cloud, the Strands Agents SDK for autonomous workflows and Amazon Bedrock AgentCore for production. One MCP server is shown at three layers (developer IDE, autonomous agent, production runtime) with no rewrites. The question on the table is whether MCP was a mistake or is still what you need to build real AI agents on AWS.
