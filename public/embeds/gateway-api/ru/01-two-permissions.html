Доступ между неймспейсами

Две границы неймспейсов, два владельца

Маршрут магазина пересекает две границы неймспейсов, и на каждой согласие даёт свой владелец. Решает владелец цели, а не тот, кто просит.

namespace: shop
HTTPRoute
команда магазина
parentRefs на Gateway shop-gateway
backendRefs на сервис payments

Тот, кто просит. Сам себе ничего не разрешает.

parentRefs: привязка
namespace: infra

shop-gateway

allowedRoutes у Gateway, сверка с лейблом gateway-access: "true" на неймспейсе shop

Лейбл ставит администратор кластера. Если команда магазина сама правит лейблы своего неймспейса, она пропускает себя сама.
