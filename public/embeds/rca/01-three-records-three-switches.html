Observability

Three records, three switches

Each record comes from a different AWS feature, and each has a switch you have to flip.

  1. Switch 1 offon

    Who called which API, and when?

    API audit trail

    AWS CloudTrail

    Enable data events

    Bedrock model calls such as InvokeModel and Converse arrive as management events. AgentCore Runtime, Gateway and Memory are among the data event resource types, and Knowledge Base retrievals are data events too. Data events are not logged by default.

  2. Switch 2 offon

    Which steps ran, failed or took time?

    Execution traces

    AgentCore Observability, Amazon CloudWatch

    Instrument your code

    The application emits OpenTelemetry traces, and AgentCore Observability stores the traces, spans and metrics in Amazon CloudWatch.

  3. Switch 3 offon

    What did the model receive and return?

    Captured content

    Bedrock model invocation logging

    Enable model invocation logging

    Captures model inputs and outputs to CloudWatch Logs, Amazon S3 or both. It is disabled by default.
