Observability

Три записи, три переключателя

Каждая запись приходит из своей возможности AWS, и у каждой есть переключатель, который включаете вы.

  1. Переключатель 1 выклвкл

    Кто вызвал какой API и когда?

    Аудит API

    AWS CloudTrail

    Включите data events

    Вызовы моделей Bedrock вроде InvokeModel и Converse приходят как management events. AgentCore Runtime, Gateway и Memory есть среди типов ресурсов для data events, а поиск по Knowledge Base тоже относится к data events. По умолчанию data events не пишутся.

  2. Переключатель 2 выклвкл

    Какие шаги выполнились, упали или заняли время?

    Трейсы выполнения

    AgentCore Observability, Amazon CloudWatch

    Инструментируйте код

    Приложение отправляет трейсы OpenTelemetry, а AgentCore Observability сохраняет трейсы, спаны и метрики в Amazon CloudWatch.

  3. Переключатель 3 выклвкл

    Что модель получила и вернула?

    Сохранённые запросы и ответы

    Логирование вызовов моделей Bedrock

    Включите логирование вызовов

    Сохраняет запросы и ответы модели в CloudWatch Logs, Amazon S3 или в оба места. По умолчанию выключено.
